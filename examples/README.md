# Patreon Scraper API – code examples

Examples for every Patreon endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/profile_info.sh`](curl/profile_info.sh) | `bash profile_info.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/profile_info.php`](php/profile_info.php) | `php profile_info.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/ProfileInfo.cs`](csharp/ProfileInfo.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/profile_info.go`](go/profile_info.go) | `go run profile_info.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/ProfileInfoExample.java`](java/ProfileInfoExample.java) | `java ProfileInfoExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/profile_info.rb`](ruby/profile_info.rb) | `ruby profile_info.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/profile_info.mjs`](nodejs/profile_info.mjs) | `node profile_info.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
